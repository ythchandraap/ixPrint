# Commercial readiness follow-up

Tanggal: 26 September 2026. Baseline: `docs/audits/2026-09-26-commercial-readiness.md`.

## Keputusan

**NO-GO untuk rilis umum tanpa pendampingan.** Perubahan kode dan gate lokal
berhasil untuk temuan R1–R4 dan R8. R5 hanya tertutup sebagian; R6, R7, dan R9
masih membutuhkan bukti artifact, credentials, browser, printer, dan perangkat
nyata. Tidak ada installer yang dibuat atau dipublikasikan pada task ini.

## Perubahan utama

- Windows printing memeriksa hasil `EndDoc` dan mengembalikan kegagalan tahap
  akhir; pesan sukses menyatakan job diterima oleh print service.
- Remote print memakai job ID logical yang stabil sebagai idempotency key dan
  tidak mengirim ulang otomatis setelah hasil ambigu.
- Reservation idempotency dipulihkan lintas restart; hasil ambigu menjawab
  HTTP 409 dengan `code: "outcome_unknown"`, job ID bila ada, dan arahan untuk
  memeriksa History/queue. Hanya state `finished` yang dapat kedaluwarsa.
- Retention menghapus History metadata dan konten secara bersama, melindungi
  job aktif, mencakup incoming documents, dan melaporkan kegagalan ke
  diagnostics.
- PDFium fetch/build memverifikasi checksum dan mempertahankan notice paket.
  Dependency notice inventory menyebut keluarga dependency yang masih perlu
  ditinjau; itu bukan clearance hukum.
- Workflow installer mendahulukan gate test/build, lalu signing dan pemeriksaan
  isi installer. Langkah signing berhenti dengan alasan eksplisit jika secret
  tidak disediakan.
- Dokumentasi menambahkan contoh browser HTTPS dan server LAN, error/retry
  semantics, Local Network Access, manual update, dan matriks hardware.

## Artifact dan risiko residual

- Artifact installer: **tidak ada**. Tidak ada installer yang dihasilkan,
  diinstal, di-upgrade, di-uninstall, atau dipublikasikan.
- Perangkat yang digunakan: tidak ada printer fisik. Tes otomatis berjalan di
  checkout macOS ini; itu tidak membuktikan printing runtime pada macOS.
- Browser yang digunakan: tidak ada sesi Chrome/Edge untuk bridge.
- Rilis tidak boleh mengklaim Windows x64, macOS Intel/Apple Silicon, atau
  Linux x64 telah lulus sebelum matriks terisi dengan bukti pada perangkat
  nyata.
- Installer verifier dan alur signing workflow belum dieksekusi terhadap
  artifact. Ketepatan ekstraksi MSI/NSIS/DMG/DEB/AppImage masih harus dibuktikan
  oleh workflow pada runner masing-masing.
- Inventaris notice dependency transitive Rust/JavaScript dan runtime platform
  belum lengkap. Periksa `src-tauri/pdfium/THIRD-PARTY-NOTICES.md` sebelum
  distribusi.
- Upgrade/uninstall mungkin berinteraksi dengan application data; backup
  manual didokumentasikan, tetapi pelestarian aktual tetap harus diuji.
- Tidak ada klaim exactly-once physical printing. Sistem menekan duplicate
  submission untuk logical retry yang dapat dikendalikan dan mengungkap hasil
  yang tidak diketahui.

## Keputusan akhir

Tetap **NO-GO** sampai setiap gate fase 9 lulus pada artifact yang sama dengan
versi/commit manifest, dependency notices lengkap, signing/notarization
terverifikasi, dan matrix OS/printer/browser serta install-to-first-print
memiliki hasil nyata. Unit test dan build lokal tidak menutup blocker tersebut.
